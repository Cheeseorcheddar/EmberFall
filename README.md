# Emberfall: Last Light

A small top-down co-op survival roguelike that runs in a modern browser.

## Play

Open `index.html` in a modern browser. Choose a class and start a solo run, or host a room and share its six-character code. Friends choose **Join a room** and enter the code from their own devices. Room-code multiplayer uses PeerJS and needs an internet connection. The host should keep the game tab open for the run.

## Controls

- Move: WASD
- Class ability: Space
- Attacks happen automatically when enemies are in range
- Touch screens: drag on the arena to move

## In the run

Survive increasingly difficult waves that scale enemy counts, health, and damage with party size. Face a random boss every fifth wave, collect experience and class-specific weapon drops, and choose shared upgrades or follow one of four class-specific upgrade paths. If a teammate falls, stand beside them for five seconds to revive them. Your ability cooldown is shown on the HUD. Weapons have distinct damage, attack-speed, range, and special-effect trade-offs.
